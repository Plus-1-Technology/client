Plugins — No Extra Subscription Required
These plugins are free to install and run on your existing Claude Teams seats. No additional vendor billing, no extra logins, no procurement. They extend what Claude can do out of the box — and the top picks below should be the first additions to your environment after Stage 1 goes live.
💡
What is a plugin, exactly?
A plugin bundles multiple capabilities — skills, MCP servers, slash commands, and tools — into one click-to-install package. Think of it like installing an app: instead of you wiring up each piece, Anthropic (or a vendor) ships the whole thing pre-configured. Plugins extend what Claude can do; connectors (see the third tab) extend what Claude can see. Many plugins are tagged "Cowork" or "Claude Code" — Cowork plugins work in your Claude Teams environment; Claude Code plugins are for developers using the command-line tool. Connectors — Where Claude Reads Your Data
Connectors let Claude securely query the apps and data sources you already use. They're read-first and run on delegated permissions — Claude only ever sees what the logged-in user can already see. TCG's roadmap has M365 connectors landing in Stage 2; this tab covers what's recommended, what to add later, and which ones to skip.
🔌
Plugins vs. Connectors — the short version
Plugins extend what Claude can do (skills, slash commands, MCP servers bundled together). Connectors extend what Claude can see — they pipe your data from Microsoft 365, Google Drive, Slack, Airtable, and 200+ other apps into Claude's context. Both run on the Model Context Protocol (MCP). Security note for TCG: connectors use OAuth delegated permissions, are read-only by default, and respect every existing share-permission your team has set in the source app. Per-connector scoping is documented in your AI Ethics SOP.
