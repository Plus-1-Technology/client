Chat How-To Basics

The everyday tasks every Hilberts user needs to know — starting chats, using folders, copying prompts, and fixing responses.

💬 Starting a New Chat

plus1tech.hatz.ai/chat — left sidebar
Secure AI Chat
New chat +
˅ Folders   No folders yet
  1. In the left sidebar, find the purple New chat + button at the top
  2. Click the + on the right side of the button
  3. A blank conversation opens — the current agent stays the same
  4. Type your first message and press Enter or click the send arrow
✅ When to Start a New Chat
Start a new chat when switching to a completely different task. Within one task — refining a quote email, adjusting an SOP — stay in the same chat. The AI remembers the full context.

📋 Copying a Saved Prompt Into the Message Bar

  1. Open your saved prompts file (Teams doc, Word file, or this training demo)
  2. Select the prompt text and copy it (Ctrl+C)
  3. Click inside the Message Secure AI box at the bottom of Chat
  4. Paste the prompt (Ctrl+V)
  5. Fill in any [brackets] with real details before hitting Send

📁 Creating Folders

  1. In the left sidebar, find the Folders section
  2. Click the + icon next to Folders
  3. Name it something meaningful: "Q2 Contractor Quotes" or "Warranty Claims 2025"
  4. Right-click any chat and choose Move to folder

🗑 Deleting a Folder

⚠ Warning
Deleting a folder may delete all chats inside it. Make sure you don't need those conversations before deleting.
  1. Find the folder in the left sidebar
  2. Right-click the folder name (or click the three-dot ⋯ menu on hover)
  3. Select Delete from the menu
  4. Confirm the deletion when prompted

🔁 Fixing a Bad AI Response

ProblemWhat to Type

Missing detail"Add a line about our 30-day lead time on Daikin VRV."
Completely wrong"Start over. I need a bid decline letter, not a follow-up."

📚 Chat How-To Basics

Common tasks every Hilberts user should know

💬 Starting a New Chat

  1. In the left sidebar, find the purple New Chat button at the top
  2. Click the + icon on the right side of that button
  3. A blank conversation opens — the active agent stays the same unless you change it
  4. Type your first message and press Enter (or click the send arrow)
💡 Tip: You don't need to start a new chat for every message. Within one conversation, you can follow up and ask for revisions. Start a new chat only when switching to a completely different task.

🔄 Switching Between Agents

  1. Click the agent/model dropdown at the top center of the chat window
  2. Under My Agents, click the agent you want to switch to
  3. The new agent takes over from this point in the conversation

📋 Copying a Prompt Into the Message Bar

  1. Open your saved prompts file (e.g., a shared Teams doc or Word file)
  2. Select the prompt text you want to use
  3. Copy it (Ctrl+C on Windows)
  4. Click inside the Message Secure AI box at the bottom of the Chat page
  5. Paste the prompt (Ctrl+V)
  6. Fill in any blanks (customer name, quote number, etc.) before hitting Send
💡 Tip: If your prompt has placeholders like [contractor name] or [quote number], always replace those before sending.

📁 Creating Folders

  1. In the left sidebar, find the Folders section below your chat list
  2. Click the + icon next to Folders
  3. Give it a descriptive name (e.g., "Q2 Contractor Quotes" or "Warranty Claims 2025")
  4. Right-click a chat name and choose Move to folder

🗑 Deleting a Folder

⚠ Heads Up: Deleting a folder may delete the chats inside it. Make sure you don't need those conversations before deleting.
  1. Find the folder you want to delete in the left sidebar
  2. Right-click the folder name (or click the three-dot menu on hover)
  3. Select Delete from the menu
  4. Confirm the deletion when prompted

🔁 If the AI Response Isn't What You Expected

  • Too long? Say: "Make this shorter — 3 sentences max."
  • Wrong tone? Say: "Make this more formal" or "Make this more conversational."
  • Missing details? Say: "Add a line about our 30-day lead time on Daikin VRV systems."
  • Wrong direction? Say: "Start over. I need a bid decline letter, not a follow-up."
🌟 You Can Always Refine: Every response is a starting point. The real power comes from the back-and-forth — tell it what to change and it will revise immediately.

🛠 Agent Editor

For admins — customize and configure your AI agents

📷 Screenshot: Agent Editor — Template Writer (ss_08598fm0a)

The Agent Editor is where your custom Hilberts agents were built and can be updated. This is an advanced, admin-only section. Most Hilberts staff will never need to access it — but knowing it exists helps you understand how your agents work.

What the Agent Editor Controls

  • Agent Name & Description — What shows in the dropdown and on cards
  • System Instructions — Detailed behind-the-scenes guidance (kept private from general users)
  • Model Selection — Which underlying AI model powers the agent
  • Tools & Capabilities — What tools the agent can access (web search, file reading, M365, etc.)
  • Starter Prompts — The "Get Started" buttons on the agent's opening screen
💡 For Hilberts Admins: If an agent needs to be updated — new product line, pricing policy change, updated quoting procedures — the Agent Editor is where those changes happen. All 5 agents can be updated independently.
