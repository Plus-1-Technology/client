📚 Chat How-To Basics

Common tasks every Hilberts user should know

💬 Starting a New Chat

  1. In the left sidebar, find the purple New Chat button at the top
  2. Click the + icon on the right side of that button
  3. A blank conversation opens — the active agent stays the same unless you change it
  4. Type your first message and press Enter (or click the send arrow)
💡 Tip: You don't need to start a new chat for every message. Within one conversation, you can follow up and ask for revisions. Start a new chat only when switching to a completely different task.

🔄 Switching Between Agents

  1. Click the agent/model dropdown at the top center of the chat window
  2. Under My Agents, click the agent you want to switch to
  3. The new agent takes over from this point in the conversation

📋 Copying a Prompt Into the Message Bar

  1. Open your saved prompts file (e.g., a shared Teams doc or Word file)
  2. Select the prompt text you want to use
  3. Copy it (Ctrl+C on Windows)
  4. Click inside the Message Secure AI box at the bottom of the Chat page
  5. Paste the prompt (Ctrl+V)
  6. Fill in any blanks (customer name, quote number, etc.) before hitting Send
💡 Tip: If your prompt has placeholders like [contractor name] or [quote number], always replace those before sending.

📁 Creating Folders

  1. In the left sidebar, find the Folders section below your chat list
  2. Click the + icon next to Folders
  3. Give it a descriptive name (e.g., "Q2 Contractor Quotes" or "Warranty Claims 2025")
  4. Right-click a chat name and choose Move to folder

🗑 Deleting a Folder

⚠ Heads Up: Deleting a folder may delete the chats inside it. Make sure you don't need those conversations before deleting.
  1. Find the folder you want to delete in the left sidebar
  2. Right-click the folder name (or click the three-dot menu on hover)
  3. Select Delete from the menu
  4. Confirm the deletion when prompted

🔁 If the AI Response Isn't What You Expected

  • Too long? Say: "Make this shorter — 3 sentences max."
  • Wrong tone? Say: "Make this more formal" or "Make this more conversational."
  • Missing details? Say: "Add a line about our 30-day lead time on Daikin VRV systems."
  • Wrong direction? Say: "Start over. I need a bid decline letter, not a follow-up."
🌟 You Can Always Refine: Every response is a starting point. The real power comes from the back-and-forth — tell it what to change and it will revise immediately.

Set up AI tasks that run automatically on a schedule

Scheduled Workflows let you automate recurring AI tasks — set it up once, and it runs on its own at whatever time and frequency you set.

🔗 Workshop — Connections

Link your external tools so the AI can work with your real data

📷 Screenshot: Connections (ss_4962x0tfg)

Connections is where you authorize the AI to access your external services — Microsoft 365, Google services, and others. Without a connection, your agents can only work with information you manually type in.

Why Connections Matter for Hilberts

  • Morning Digest needs your Microsoft 365 connection to pull emails, calendar, and Teams messages
  • Quote Follow-Up Writer can send emails through Outlook when connected

How to Add a Connection

  1. Click Connections in the Workshop sidebar
  2. Find the service you want to connect (e.g., Microsoft 365)
  3. Click Connect or Add Integration
  4. Sign in to the external service and grant permissions
  5. The connection shows as active (green checkmark) when complete
🔒 Your Data Stays Secure: Connections use OAuth (standard industry-safe authorization). Hilberts AI never stores your Microsoft 365 password — only receives temporary, limited access.
