Starting a New Chat

New Chat + Button

ProblemWhat to Type
Response is too long"Make this shorter — 3 sentences max."
Wrong tone"Make this more formal" or "more conversational"
Missing detail"Add a line about our 30-day lead time on Daikin VRV."
Completely wrong"Start over. I need a bid decline letter, not a follow-up."

Creating a Folder

In the left sidebar, find the Folders section → click the + icon → name it something meaningful like "Q2 Contractor Quotes" or "Warranty Claims 2025" → right-click any chat and choose Move to folder.

Deleting Folders — Warning

Deleting a folder may delete all chats inside it. Right-click the folder → select Delete → confirm. Make sure you don't need those conversations before deleting.
